=== Final DATA MATRIX DRAFT ===

### UserAccount
- **Input:** User registration data (name, email, password, phone number)
- **Activity:** Validation of user data; creation of user account
- **Output:** User account created; user session initiated

### UserAddress
- **Input:** Address data (street, city, state, zip code)
- **Activity:** Validation of address; association with user account
- **Output:** Address saved; user profile updated

### ProductCatalog
- **Input:** Product listing data (name, description, price, category, availability)
- **Activity:** Update product catalog; refresh inventory status
- **Output:** Product catalog updated; inventory status reflected

### CustomerOrder
- **Input:** User selection of products and delivery preferences
- **Activity:** Validation of order; creation of order record
- **Output:** Order created; order confirmation sent

### OrderItem
- **Input:** Product ID, quantity
- **Activity:** Association with customer order; update inventory
- **Output:** Order item added; inventory adjusted

### DeliveryPreference
- **Input:** User selected delivery time (15 minutes, 30 minutes)
- **Activity:** Validation of delivery preference; assignment to order
- **Output:** Delivery preference saved; order updated

### PaymentTransaction
- **Input:** Payment method and details (credit card, PayPal)
- **Activity:** Validation of payment; authorization of transaction
- **Output:** Payment processed; order status updated to paid

### OrderStatus
- **Input:** Order ID, status update (pending, confirmed, processing, dispatched, delivered)
- **Activity:** Update order status; notify user
- **Output:** Order status updated; user notified

### DeliveryAgentAssignment
- **Input:** Order ID, delivery agent availability
- **Activity:** Assignment of delivery agent; update order record
- **Output:** Delivery agent assigned; order updated

### DeliveryRoute
- **Input:** Delivery agent location, user address
- **Activity:** Calculation of delivery route; optimization of delivery path
- **Output:** Delivery route calculated; delivery path optimized

### DeliveryNotification
- **Input:** Order ID, delivery status
- **Activity:** Notification of delivery status update; update user
- **Output:** Delivery notification sent; user updated

### InventoryUpdate
- **Input:** Sold products, delivery status
- **Activity:** Update inventory levels; track stock availability
- **Output:** Inventory levels updated; stock status reflected

### CustomerReview
- **Input:** Order ID, review text, rating
- **Activity:** Validation of review; association with order
- **Output:** Review saved; product rating updated

### FeedbackProcessing
- **Input:** Customer review
- **Activity:** Analysis of feedback; update product catalog or customer service
- **Output:** Feedback processed; catalog or customer service updated
